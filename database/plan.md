# Database and Store Procedure Generator
## Purpose
Generate an approriate database and store procedure for the application.
## Use this skill when
– The user wants to create a database for the application.
– The available information includes schema design, business requirements, or use cases.
– The user has completed the user discovery stage and wants to summarize the findings
into a persona.
## Required inputs
– Database schema
## Output
- A completed database and store procedure following the selected database schema.
- Provide a sql separate file for creating database and store procedure.
- Provide a markdown file for explaining database and store procedure.
## Workflow
1. Read the available database schema design.
2. Infer any missing table, columns or relationships when appropriate.
3. Generate a realistic database and store procedure.
4. Ensure consistency between schema and store procedure.
5. Produce the database and store procedure in SQL..
