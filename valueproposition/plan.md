# Value Proposition Generator
## Purpose
Generate a value proposition from user research findings and persona.
## Use this skill when
– The user wants to create a value proposition.
– The available information includes user goals, tasks, pain points, motivations, or
wishes.
– The user has completed the user discovery stage and wants to summarize the findings
into a persona.
## Required inputs
- Persona created in previous step
## Output
- A completed value proposition
## Workflow
1. Read the available persona data.
2. Infer any missing persona attributes when appropriate.
3. Generate a value proposition based on the pain points, wishes and customer jobs
4. Ensure consistency
5. Produce the value proposition in Markdown.
