# Scenario Generator
## Purpose
Generate two scenario with one based on the existing system and one based on the new system
## Use this skill when
– The user wants to create scenarios for the system.
## Required inputs
- Persona
## Output
- Two scenarios for the existing system and the new interaction for the new system
## Workflow
1. Read the available persona.
2. Design a new interaction for the user in the new system.
3. Produce the two scenarios in Markdown.
4. The scenario of the existing system should be based on the pain points of the persona to highlight existing problems with the new system
5. The scenario of the new system should be based on the persona to highlight how the new system solve the existing problems or to highlight what is new in the interaction.
