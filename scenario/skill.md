# Persona generator skill
Generate a realistic persona based on user discovery findings.
## Rules
- Answer in Vietnamese
– Do not invent impossible facts.
– Keep all attributes internally consistent.
- Ensure the scenario describe the task being done to the system
- For the scenario for the existing system, based on the persona to highlight existing problems with the new system
- For the scenario for the new system, based on the persona to highlight how the new system solve the existing problems or to highlight what is new in the interaction.
